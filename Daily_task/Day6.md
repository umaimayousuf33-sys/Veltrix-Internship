# Day 6 – Website Scan

## Objective
To perform a website scan and identify open ports using Nmap.

## Tool Used
- Nmap

## Command Used
nmap -A example.com

## Practical Steps
- Opened terminal in Kali Linux
- Executed Nmap scan on target website
- Observed open ports and services
- Identified running services on target

## Theory

### Open Ports Meaning
- Port 80: HTTP (non-secure web traffic)
- Port 443: HTTPS (secure web traffic)
- Port 22: SSH (secure remote login)
