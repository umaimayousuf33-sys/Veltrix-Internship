# 🔎 Day 7 – WhatWeb & WHOIS (Footprinting)

## 📌 Overview
This task focuses on footprinting, the first step in cybersecurity, where we gather information about a target using tools like WhatWeb and WHOIS

## 🎯 Objective
- Identify technologies used by a website  
- Gather domain registration details  
- Understand footprinting techniques  

## 🛠️ Tools Used
- Kali Linux  
- WhatWeb  
- Whois  

## ⚙️ Practical Commands

### WhatWeb Scan
whatweb example.com

### Whois Lookup
whois example.com

## 📊 Observations
- WhatWeb detected website technologies and server details  
- Whois provided domain registration information  
- Public data reveals useful information about the target

## 📚 Theory – What is Footprinting?

Footprinting is the process of collecting information about a target system, network, or website. It is the first step in ethical hacking and helps in understanding the target before further analysis.
