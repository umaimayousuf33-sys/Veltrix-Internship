## Theory

### IP Address
A unique address assigned to each device on a network.

### MAC Address
A physical hardware address assigned to a network interface.

### DNS
Domain Name System converts domain names (like google.com) into IP addresses.

### Port
A communication endpoint used by applications (e.g., port 80 for HTTP).

### TCP vs UDP
TCP is connection-oriented and reliable.  
UDP is faster but does not guarantee delivery.
