# Day 15 – SQLi with Burp Suite

## Objective
To intercept login requests and modify parameters using Burp Suite.

## Practical
- Opened Burp Suite
- Enabled intercept
- Submitted login request
- Captured request
- Modified username parameter
- Forwarded request

## Payload Used
' OR 1=1--

## Theory
Burp Suite is a web security testing tool used to analyze and modify HTTP requests.

Parameter modification helps identify vulnerabilities like SQL Injection.

## Conclusion
Learned how request interception works and how modified parameters can be used for security testing.
